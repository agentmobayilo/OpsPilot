## Why this project exists
Build a monetizable Google Workspace SaaS that converts inbox messages into actions: replies, tasks, follow-ups, meetings, and CRM updates.

## Current Scope (MVP)
- OAuth connection to Google
- AI inbox triage + lead detection
- Drafted replies (human approval)
- Follow-up reminders
- Google Sheets CRM sync
- Daily briefing dashboard
